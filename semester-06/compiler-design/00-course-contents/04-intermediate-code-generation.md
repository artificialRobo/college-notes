## Unit 4: Intermediate Code Generation and Code Generation (12 Hours)

### 4.1 Intermediate Code Generation

* Introduction to Intermediate Code Generation
* Prefix and Postfix Notation
* Syntax Trees
* Evaluation of Expressions
* Three-Address Code
* Quadruple, Triple, and Indirect Triple Representations

### 4.2 Syntax-Directed Translation

* Synthesized Attributes
* Inherited Attributes
* Intermediate Languages
* Translation of Declarations
* Translation of Assignment Statements
* Translation of Boolean Expressions
* Translation of Case Statements
* Backpatching
* Procedure Calls

### 4.3 Code Generation

* Introduction to Code Generation
* Issues in the Design of a Code Generator
* Target Machine Considerations
* Runtime Storage Management
* Simple Code Generator
* Code Generation Algorithm
* Register and Address Descriptors

**Learning Outcomes**
After completing this unit, students will be able to:

* Generate intermediate representations for source programs.
* Apply syntax-directed translation techniques.
* Generate three-address code and related representations.
* Explain runtime storage management and target machine considerations.
* Design and implement basic code generation algorithms.
