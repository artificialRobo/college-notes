## Unit 5: Code Optimization and Runtime Environment (12 Hours)

### 5.1 Introduction to Code Optimization

* Code Optimization
* Principal Sources of Optimization
* Function-Preserving Transformations

### 5.2 Optimization Techniques

* Loop Optimization
* Peephole Optimization
* Directed Acyclic Graph (DAG)-Based Optimization

### 5.3 Flow Analysis

* Basic Blocks
* Flow Graphs
* Global Data Flow Analysis
* Efficient Data Flow Algorithms

### 5.4 Runtime Environment

* Runtime Environments
* Source Language Issues
* Storage Organization
* Activation Records
* Storage Allocation Strategies

**Learning Outcomes**
After completing this unit, students will be able to:

* Explain the objectives and techniques of code optimization.
* Apply local and global optimization methods to intermediate code.
* Analyze programs using basic blocks, flow graphs, and data flow analysis.
* Describe runtime environments and storage organization.
* Explain activation records and memory allocation strategies used during program execution.
