# Hill Climbing

## Introduction

**Hill Climbing** is one of the simplest and most widely used **local search algorithms** in Artificial Intelligence. It is an **iterative improvement algorithm** that starts with an initial solution and repeatedly moves to a neighboring solution that improves the objective function.

The algorithm attempts to reach the best possible solution by continuously moving in the direction of increasing value (for maximization problems) or decreasing cost (for minimization problems).

## Definition

Hill Climbing is a local search algorithm that repeatedly moves from the current state to a neighboring state with a better evaluation value until no better neighbor exists.

The algorithm is called “hill climbing” because it is analogous to climbing a hill where every step moves upward toward a higher elevation.

## Basic Idea

Hill Climbing begins with an initial state and evaluates its neighboring states.

At each iteration:

1. Generate neighboring states.
2. Evaluate each neighbor.
3. Select a better neighbor.
4. Move to that neighbor.
5. Repeat until no improvement is possible.

The algorithm maintains only **one current state** and does not store the search tree.

## Working Principle

For a maximization problem:

```text
Start
  |
  v
Current State
  |
  v
Generate Neighbors
  |
  v
Choose Better Neighbor
  |
  v
Move to Neighbor
  |
  v
Repeat Until No Improvement
```

The search stops when the current state is better than all of its neighboring states.

## Algorithm

### Hill Climbing Algorithm

**Input:** Initial state

**Output:** Local optimum

```text
HillClimbing(initial_state)

1. current ← initial_state
2. loop
3.     neighbor ← best neighbor of current
4.     if neighbor is not better than current then
5.          return current
6.     current ← neighbor
```

The algorithm terminates when no neighboring state provides a better evaluation.

## Example

Suppose the objective is to maximize the evaluation function.

| State | Value |
| --- | --- |
| A | 2 |
| B | 5 |
| C | 8 |
| D | 10 |
| E | 9 |

Search sequence:

```text
A -> B -> C -> D
```

Since D has the highest neighboring value, the algorithm stops at D.

The algorithm continuously moves upward until reaching the peak.

## Types of Hill Climbing

Several variants of Hill Climbing are used in practice.

### Simple Hill Climbing

The algorithm examines neighbors sequentially and moves to the **first better neighbor** encountered.

Algorithm:

```text
For each neighbor
    if neighbor is better
         move immediately
```

Advantages:

- Fast.
- Easy to implement.

Disadvantages:

- May choose a poor improving move.

### Steepest-Ascent Hill Climbing

Also called **best-improvement hill climbing**.

The algorithm evaluates **all neighbors** and selects the best one.

Example:

Current state value = 10

Neighbors:

| Neighbor | Value |
| --- | --- |
| N1 | 11 |
| N2 | 14 |
| N3 | 12 |

The algorithm chooses **N2**.

Advantages:

- Better decision making.
- Often finds better local optima.

Disadvantages:

- More computation per iteration.

### First-Choice Hill Climbing

Neighbors are generated randomly.

The algorithm moves to the **first randomly generated better neighbor**.

Advantages:

- Efficient for very large neighborhoods.

Disadvantages:

- May require many random trials.

### Stochastic Hill Climbing

Selects among better neighbors **probabilistically**.

Better neighbors have a higher probability of being selected.

Advantages:

- More exploration.
- Less deterministic behavior.

Disadvantages:

- May converge more slowly.

## Search Space Example

Consider the 8-Queens problem.

Initial arrangement:

```text
Q . . .
. Q . .
. . Q .
. . . Q
```

Neighboring states are generated by moving one queen.

The evaluation function counts the number of attacking queen pairs.

The algorithm attempts to **minimize conflicts**.

## Objective Function

For maximization:

```text
f(s) = Value(s)
```

For minimization:

```text
f(s) = Cost(s)
```

Hill Climbing always moves toward a better objective value.

## Problems in Hill Climbing

Hill Climbing is not guaranteed to find the global optimum.

Three major difficulties occur.

### Local Maximum

A **local maximum** is better than all neighboring states but worse than the global maximum.

Example:

```text
      Global Maximum
           *
          / \
         /   \
   *----*     \____
  /
 *
Local Maximum
```

The algorithm becomes trapped at the local maximum.

### Plateau

A plateau is a flat region where neighboring states have equal values.

Example:

```text
5 ---- 5 ---- 5 ---- 5
```

The algorithm has no direction for improvement.

Possible outcomes:

- Random wandering.
- Premature termination.

### Ridge

A ridge is a narrow ascending path requiring multiple coordinated moves.

Example:

```text
      *
     /
    *
   /
  *
```

Simple neighbor moves may fail to follow the ridge.

## Illustration of Local Maximum

Suppose the landscape is:

```text
          10
         /  \
        8    12
       /
      9
```

Starting from 9:

- Move to 10.
- Stop.

The global maximum 12 is never reached.

## Performance Analysis

### Completeness

Hill Climbing is **not complete**.

It may fail to reach the goal even if one exists.

### Optimality

Hill Climbing is **not optimal**.

It may stop at a local optimum.

### Time Complexity

If:

- **I** = Number of iterations.
- **k** = Number of neighbors.

Time complexity:

```text
O(I x k)
```

For steepest-ascent hill climbing, all neighbors are evaluated.

### Space Complexity

Only the current state is stored.

Space complexity:

```text
O(1)
```

This is a major advantage of Hill Climbing.

## Advantages

- Very low memory usage.
- Easy to implement.
- Fast for many optimization problems.
- Suitable for large search spaces.
- Often finds reasonably good solutions quickly.

## Disadvantages

- Gets trapped in local maxima.
- Suffers from plateaus and ridges.
- Sensitive to the initial state.
- No guarantee of optimality.
- May terminate prematurely.

## Improving Hill Climbing

Several techniques reduce its limitations.

### Random Restart Hill Climbing

Run Hill Climbing multiple times from different random initial states.

Advantages:

- Increases probability of finding the global optimum.

### Sideways Moves

Allow moves to neighbors with equal evaluation values.

Helps escape plateaus.

### Stochastic Variants

Use randomization to improve exploration.

### Simulated Annealing

Allows occasional downhill moves.

Greatly reduces the chance of becoming trapped in local optima.

## Applications

Hill Climbing is used in:

- 8-Queens problem.
- Traveling Salesman Problem.
- Scheduling.
- Resource allocation.
- Feature selection.
- Neural network optimization.
- Circuit design.
- Robotics.
- Timetable generation.

## Comparison with Other Local Search Algorithms

| Feature | Hill Climbing | Simulated Annealing |
| --- | --- | --- |
| Moves only to better states | Yes | No |
| Can accept worse states | No | Yes |
| Escapes local maxima | Difficult | Better |
| Memory usage | O(1) | O(1) |
| Implementation | Simple | Moderate |

## Practical Example

Suppose a delivery company wants to minimize travel distance.

Current route:

100 km.

Neighboring routes:

| Route | Distance |
| --- | --- |
| R1 | 95 km |
| R2 | 92 km |
| R3 | 98 km |

Hill Climbing chooses **R2**.

This process repeats until no shorter neighboring route exists.

## Key Points

- Hill Climbing is a **local search algorithm**.
- It is an **iterative improvement algorithm**.
- The algorithm always moves to a **better neighboring state**.
- It maintains **only one current state**.
- Space complexity is **O(1)**.
- It is **not complete** and **not optimal**.
- Major problems are **local maxima, plateaus, and ridges**.
- Variants include **simple, steepest-ascent, first-choice, and stochastic hill climbing**.
- Random restart hill climbing improves the probability of finding the global optimum.
