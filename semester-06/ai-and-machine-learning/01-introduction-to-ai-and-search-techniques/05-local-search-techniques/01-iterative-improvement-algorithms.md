# Iterative Improvement Algorithms

## Introduction

**Iterative Improvement Algorithms** are a class of **local search algorithms** that begin with an initial solution and repeatedly improve it by making small modifications. Instead of constructing a complete search tree like uninformed or informed search algorithms, these algorithms operate directly on candidate solutions and attempt to improve them iteratively.

The primary objective is to find a **better solution** at each step until no further improvement is possible or a stopping condition is reached.

## Definition

An iterative improvement algorithm is a local search method that starts from an initial state and repeatedly moves to a neighboring state with a better objective value until a local optimum or termination condition is reached.

These algorithms are widely used for **optimization problems** where the goal is to maximize or minimize an objective function.

## Basic Concept

Iterative improvement algorithms maintain **only one current solution** in memory.

At each iteration:

1. Generate neighboring solutions.
2. Evaluate their quality.
3. Select a better neighbor.
4. Replace the current solution.
5. Repeat the process.

The algorithm gradually improves the solution over time.

## Local Search Framework

The general structure of an iterative improvement algorithm is:

```text
Initial Solution
        |
        v
Generate Neighbors
        |
        v
Evaluate Neighbors
        |
        v
Choose Better Neighbor
        |
        v
Update Current Solution
        |
        v
Stopping Condition?
```

Unlike graph search algorithms, local search algorithms usually do **not store all previously visited states**.

## Search Space

A **search space** consists of all possible candidate solutions.

Example:

For the 8-Queens problem:

- Each arrangement of queens is a state.
- Neighboring states are generated by moving one queen.

Example search space:

```text
S1 ---- S2 ---- S3
 |       |       |
S4 ---- S5 ---- S6
```

The algorithm moves from one state to another based on the objective function.

## Objective Function

Iterative improvement algorithms require an **objective (evaluation) function**.

For minimization problems:

```text
f(s) = Cost(s)
```

For maximization problems:

```text
f(s) = Value(s)
```

The algorithm attempts to:

- Minimize cost, or
- Maximize value.

## Neighborhood Function

A **neighborhood function** defines which states can be reached from the current state.

Example:

In the Traveling Salesman Problem (TSP):

Current tour:

```text
A -> B -> C -> D -> A
```

Neighbor:

```text
A -> C -> B -> D -> A
```

A small change creates a neighboring solution.

## General Algorithm

### Iterative Improvement Algorithm

```text
IterativeImprovement(initial_state)

1. current ← initial_state
2. repeat
3.     generate neighbors of current
4.     choose the best neighbor
5.     if best neighbor is better than current then
6.          current ← best neighbor
7.     else
8.          terminate
9. return current
```

The algorithm terminates when no better neighboring state exists.

## Example

Suppose the objective is to minimize:

| State | Cost |
| --- | --- |
| A | 12 |
| B | 9 |
| C | 7 |
| D | 5 |
| E | 6 |

Starting from **A**:

```text
A -> B -> C -> D
```

Since D has the minimum cost among its neighbors, the algorithm stops.

## Characteristics of Iterative Improvement Algorithms

### Uses Local Information

The algorithm evaluates only neighboring states.

### Maintains One Current State

Memory usage is very small.

### Suitable for Optimization

Designed for optimization rather than pathfinding.

### May Get Stuck

Can terminate at a **local optimum**.

## Types of Iterative Improvement Algorithms

Common iterative improvement algorithms include:

- Hill Climbing
- Steepest-Ascent Hill Climbing
- First-Choice Hill Climbing
- Stochastic Hill Climbing
- Simulated Annealing
- Local Beam Search

Hill Climbing and Simulated Annealing are the most important algorithms in most university syllabi.

## Local Optimum

A **local optimum** is a state that is better than all of its neighboring states but is not the best solution overall.

Example:

```text
          Global Optimum
               *
              / \
             /   \
        *---*     \____
       /
      *
Local Optimum
```

The algorithm may stop at the local optimum even though a better solution exists elsewhere.

## Common Problems

### Local Maximum

The search becomes trapped at a locally best solution.

### Plateau

A flat region where neighboring states have the same evaluation.

Example:

```text
5 ---- 5 ---- 5 ---- 5
```

No clear direction of improvement exists.

### Ridge

A narrow path requiring multiple coordinated moves.

Example:

```text
       *
      /
     *
    /
   *
```

Simple local moves may fail to progress.

## Performance Measures

The effectiveness of an iterative improvement algorithm depends on:

### Solution Quality

How close the final solution is to the optimal solution.

### Convergence Speed

Number of iterations required.

### Memory Usage

Usually very low.

### Robustness

Ability to avoid poor local optima.

## Time Complexity

Let:

- **n** = Number of variables.
- **k** = Number of neighbors examined per iteration.
- **I** = Number of iterations.

Time complexity:

```text
O(I x k)
```

Actual complexity depends on the neighborhood size and evaluation function.

## Space Complexity

Since only the current state and a few neighbors are stored,

```text
O(1)
```

or

```text
O(k)
```

Memory efficiency is a major advantage.

## Advantages

- Very low memory usage.
- Easy to implement.
- Effective for large optimization problems.
- Can quickly find reasonably good solutions.
- Suitable for continuous and discrete optimization.

## Disadvantages

- May get trapped in local optima.
- No guarantee of finding the global optimum.
- Performance depends heavily on the initial state.
- Sensitive to neighborhood design.
- May terminate prematurely.

## Applications

Iterative improvement algorithms are widely used in:

- Traveling Salesman Problem
- Scheduling
- Resource allocation
- Machine learning optimization
- Neural network training
- Circuit design
- Vehicle routing
- Robotics
- Timetable generation

## Comparison with Graph Search Algorithms

| Feature | Graph Search | Iterative Improvement |
| --- | --- | --- |
| Maintains search tree | Yes | No |
| Stores many states | Yes | No |
| Memory usage | High | Low |
| Path finding | Yes | Usually No |
| Optimization | Limited | Excellent |
| Local information | No | Yes |

## Practical Example: Scheduling

Suppose a university timetable has conflicts.

Current schedule:

- 12 conflicts.

A neighboring schedule:

- 10 conflicts.

The algorithm replaces the current schedule with the better schedule.

This process continues until no neighboring timetable has fewer conflicts.

## Relationship with Hill Climbing

Hill Climbing is the **simplest and most important iterative improvement algorithm**.

It always moves to a better neighboring state.

Therefore, Hill Climbing is considered a specific implementation of the iterative improvement framework.

## Key Points

- Iterative improvement algorithms are **local search algorithms**.
- They maintain **only one current solution**.
- The algorithm repeatedly moves to a **better neighboring state**.
- They are primarily used for **optimization problems**.
- Memory complexity is usually **O(1)**.
- They may become trapped in **local optima, plateaus, and ridges**.
- Hill Climbing and Simulated Annealing are important iterative improvement algorithms.
- The quality of the neighborhood function significantly affects performance.
