## Unit 4: Machine Learning Fundamentals (12 Hours)

### 4.1 Introduction to Machine Learning

* Learning from Agents
* Inductive Learning
* Types of Machine Learning

### 4.2 Supervised Learning

* Introduction to Supervised Learning
* Learning Decision Trees
* Support Vector Machines (SVM)

### 4.3 Neural Networks

* Introduction to Neural Networks
* Perceptron
* Multi-layer Feed Forward Networks

### 4.4 Probabilistic Learning

* Bayesian Belief Networks

**Learning Outcomes**
After completing this unit, students will be able to:

* Explain the concepts and categories of machine learning.
* Apply supervised learning techniques for classification tasks.
* Describe the architecture and working of neural networks.
* Explain the principles of Bayesian belief networks for probabilistic reasoning.
* Compare different supervised learning models based on their applications.
