### 2.2 Knowledge-Based Agents

* Introduction to First-Order Logic (FOL)

**Learning Outcomes**
After completing this unit, students will be able to:

* Explain decision-making techniques used in game-playing agents.
* Design knowledge-based agents for intelligent environments.
* Represent knowledge using propositional and first-order logic.
* Apply logical reasoning to solve AI problems.
* Model dynamic environments using logical representations.
