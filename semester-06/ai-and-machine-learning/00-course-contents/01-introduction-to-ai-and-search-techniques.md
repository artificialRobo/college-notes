## Unit 1: Introduction to Artificial Intelligence and Search Techniques (12 Hours)

### 1.1 Introduction to Artificial Intelligence

* Introduction to Artificial Intelligence (AI)
* History of AI
* Intelligent Agents
* Structure of Intelligent Agents
* Types of Environments

### 1.2 Problem Solving by Search

* Problem Solving Methods
* Problem Solving Agents
* Problem Formulation

### 1.3 Uninformed Search Strategies

* Breadth-First Search (BFS)
* Uniform Cost Search (UCS)
* Depth-First Search (DFS)
* Depth-Limited Search
* Bidirectional Search

### 1.4 Informed Search Strategies

* Best-First Search
* Heuristic Functions
* Memory-Bounded Search
* A* Search Algorithm
* Simplified Memory-Bounded A* (SMA*)

### 1.5 Local Search Techniques

* Iterative Improvement Algorithms
* Hill Climbing
* Simulated Annealing

### 1.6 Performance Analysis

* Measures of Performance
* Analysis of Search Algorithms

**Learning Outcomes**
After completing this unit, students will be able to:

* Explain the evolution and applications of Artificial Intelligence.
* Describe the architecture of intelligent agents and problem-solving methods.
* Apply uninformed and informed search algorithms to solve AI problems.
* Compare heuristic and local search techniques.
* Evaluate search algorithms based on performance measures.
